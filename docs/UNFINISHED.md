# 交付边界与后续事项

本文件说明发布契约及外部边界，不替代 Issue #3 的逐项验收账本。当前新版的已测 SHA、剩余问题和唯一下一步见 [CURRENT_TASK.md](CURRENT_TASK.md)；[ACCEPTANCE.md](ACCEPTANCE.md) 保留历史验收映射。历史 release 的 `PROVENANCE.json` 和证据包只证明相应历史版本，不能自动验收当前源码。

## 已纳入强制发布门禁

双栏真实操作、SSH 双任务 Running/Pending/History、失败与取消、重启恢复、CodeMirror 配置保存/遮罩、权限确认、受保护本机下载、指纹变化阻断、六平台原生窗口与打包后再次运行，均由可复现 workflow 检查。复杂策略包含 48 个 direct/SOCKS/SSH 方向/权限/方法用例、8 个官方 Hans 角色/方法用例、真实 TCP 阻断回退、缓存失效、取消延迟和清理。

旧描述“SOCKS/SSH/Hans 不支持 ncat 重放”已过时：当前通过认证加密载体重放 ncat，不把代理口令放进进程参数。六平台入口虽保留，但按用户后续决定，当前只优先验证 macOS arm64；其余平台待用户确认后再构建/发布，不是本轮自动扩展的验收矩阵。以后发布某平台时，仍要求该平台真实启动，而非仅交叉编译。

## 当前 Mac 候选交付链（技术范围已有 hosted 证据）

新候选给现有打包器增加显式 `--platform darwin-arm64`，无参数仍严格要求六平台。主门禁汇合原 SSH 三组，PR/main 只运行一次 SSH；旧 release 关闭 Mac 候选旁路并依赖同一包含 SSH 的 validate，不重复生产同名工件。打包只消费同事件完整成功收据和原始 native 字节，前端依赖仅用于收集锁定许可证，不重新编译产品。

单平台包包含对应源码、GPL/FlySSH/Hans/前端许可、完整校验和与来源清单；不递归收入原始日志。独立 Mac runner 解包后验证原权限/签名/字节并复用原 native-smoke，另存验收收据，不重新签名或修改产品包。4f 的唯一 hosted 主链已有实际归档与独立解包结果，最终收据绑定严格提取时固定的原清单；四格 recorder 旧红新绿也已核验。确切源码、产物哈希和运行事实见 CURRENT_TASK.md，而非用本段概述冒充全需求通过；D/F4 选择、A–P 全部验收与用户认可仍独立，未合并或发布。

## 仍需外部发布者身份材料

- Apple Developer ID 签名与 notarization 没有配置；macOS 使用 ad-hoc 签名并验证完整性。
- Windows Authenticode 发布者签名没有配置。

未提供证书/账号身份，不能声称签名认证已完成。应用和 workflow 不关闭 Gatekeeper、SmartScreen 或其他系统安全设置。

## 测试不能替代的边界

任意用户 shell 插件、自定义提示符、多日运行、所有网络拓扑和旧版操作系统不可能由一组固定 CI 用例穷尽。发布候选表示所列自动化验收通过，不表示每个环境已获人工认可。Linux GUI 仍有系统图形依赖；远端主要完整支持 Linux。网络完全断开时无法保证立即清理远端文件；只处理本程序有合法所有权标记的临时资源，不通过扩大删除范围换取“零残留”口号。

## 保持不在本批次范围

原 TUI 不替换；旧 Fyne 离线麒麟 libGL/X11 问题仍按原决定保留；无桌面服务器 Web UI 未加入。没有新增后台监视或私有 runner。
